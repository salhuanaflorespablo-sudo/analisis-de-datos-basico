# 📊 Ejercicio C: Análisis de Datos Básico con Python

Este repositorio contiene la solución al Ejercicio C de análisis de datos básico, utilizando la librería **Pandas** para la manipulación de datos y **Matplotlib** para la visualización.

---

## 📝 Descripción del Ejercicio

El objetivo de este script es realizar un mini-análisis de datos a partir de un archivo CSV simple. Las tareas completadas son:

1.  Lectura de datos desde `text.csv` (o `datos.csv`).
2.  Cálculo de **estadísticas descriptivas** (media, mediana y desviación estándar) para ambas columnas.
3.  Generación de un **Gráfico de Dispersión (Scatter Plot)** para visualizar la relación entre `Col1` y `Col2`.

## 🛠️ Requisitos e Instalación

Para replicar este análisis, necesitas tener **Python 3.x** instalado.

1.  **Clonar el Repositorio:**
    ```bash
    git clone [https://es.stackoverflow.com/questions/394119/como-obtener-la-url-del-repositorio-de-git-hub](https://es.stackoverflow.com/questions/394119/como-obtener-la-url-del-repositorio-de-git-hub)
    cd nombre-del-repositorio/Analisis_de_datos
    ```

2.  **Configurar el Entorno Virtual:**
    ```bash
    python -m venv .venv
    # Activar el entorno (ejemplo en Windows)
    .venv\Scripts\activate
    ```

3.  **Instalar Dependencias:**
    *(Si hubieras subido el requirements.txt, usarías 'pip install -r requirements.txt'. Como no está, listamos las librerías necesarias)*
    ```bash
    pip install pandas matplotlib
    ```
